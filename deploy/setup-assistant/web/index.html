Setup SmartPresensi

Asisten instalasi & diagnostik

Selamat datang

Wizard ini membantu Anda memasang dan mengonfigurasi SmartPresensi di komputer ini (Windows). Tidak ada berkas yang diubah tanpa persetujuan Anda.

Cek sistem operasi

Pastikan sistem memenuhi syarat minimal sebelum melanjutkan.

Cek komponen

Komponen dibundel bersama paket ini dan harus bisa dijalankan.

Panduan instalasi

Hak administrator aktif. Anda dapat melanjutkan untuk memasang layanan sistem (MySQL, Apache, dan Supervisor).

Wizard berjalan tanpa hak administrator. Untuk memasang layanan sistem, tutup jendela ini dan jalankan start-setup.ps1 sebagai Administrator, lalu buka kembali wizard.

  • 1. Komponen akan dipasang dari bundel lokal (tanpa unduhan internet).
  • 2. Konfigurasi disimpan di folder data\ dan app\.env.
  • 3. Layanan didaftarkan agar otomatis berjalan saat komputer menyala.

Konfigurasi

Akun Administrator Pertama

Akun ini dibuat otomatis saat pemasangan dan dipakai untuk masuk pertama kali.

Isi email yang valid dan kata sandi minimal 8 karakter.

Konfigurasi tersimpan.

Alamat web:

Kata sandi database dibuat otomatis (disimpan pada app\.env).

Menyimpan konfigurasi menulis php.ini, my.ini, dan httpd.conf pada bundel. Bila app\.env sudah ada, isinya dipertahankan (APP_KEY dan pengaturan WhatsApp tidak diubah).

Layanan sistem

Layanan berikut akan dipasang dan dijalankan otomatis.

Pemasangan layanan memerlukan hak administrator.

Gunakan Perbaiki & Daftar Ulang setelah memindahkan folder bundle ke lokasi/PC lain. Tindakan ini menulis ulang konfigurasi ke path saat ini dan mendaftarkan ulang layanan, tanpa mengubah app\.env (APP_KEY & WhatsApp tetap).

Uji sistem

Memeriksa apakah web, database, dan layanan berjalan normal.

Bila uji database gagal karena kata sandi tidak cocok, gunakan Reset Kata Sandi Database untuk menyetel ulang kata sandi MySQL agar sama dengan app\.env (data tetap utuh).

Selesai

Setup telah mencapai langkah akhir. Anda dapat menutup wizard ini.
